# Experimental results

`ml-dsa-m4-exp-res/` and `ml-dsa-ref-exp-res/` are the saved analysis arrays used to redraw the paper figures. `y_valid_bp/` contains the original train/test index files already present in this EXP directory. Fresh results from the reproducibility CLI are written separately to `../reproducibility/<profile>/exp_res/`. See the [archive README](../README.md).
